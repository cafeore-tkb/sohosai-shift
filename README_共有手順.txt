Shift Maker（オフライン配布版）

■ 開き方
1. 受け取った ShiftMaker_Offline.zip を右クリック →「すべて展開」で展開します（Mac はダブルクリックで展開）。
2. Windows：「Shift Maker を開く.cmd」をダブルクリックします。
   Mac　　：「Shift Maker を開く.command」をダブルクリックします。
   （index.html を直接ダブルクリックしても開けます）
3. ブラウザ（Chrome／Edge／Safari など）でアプリが開きます。インターネット接続は不要です。

※ Mac で「開発元を確認できないため開けません」と表示された場合は、
　「Shift Maker を開く.command」を右クリック（Controlキー＋クリック）→「開く」を選び、確認画面で「開く」を押してください。
　それでも開けない場合は、index.html をダブルクリックして開いてください。
※ 画面を閉じたり再読み込みしたりすると、作業内容は消えます。区切りごとに「CSVを書き出す」か「印刷ビュー」で保存してください。


■ 画面の構成
画面上部のタブで切り替えます。タブの右（または下）には、スタッフ数・必要枠・割当済み・未割当の件数と充足率が常に表示されます
（同じ人が同じ時間に2つの枠に入っている「重複」が起きたときだけ、その件数も赤で表示されます）。
右上の「印刷ビュー」「CSVを書き出す」はどのタブからでも使えます。

　1 読み込み　　：アンケート回答CSVを読み込みます。「50名サンプルを読み込む」で動きを試せます。
　2 勤務可能表　：日付ごとに、誰が何時に勤務できるかを30分単位の○で表示します。先頭行は時間帯ごとの勤務可能人数です。
　　　　　　　　　セルをクリック（ドラッグでまとめて）すると ○／— を切り替えられます（後からの変更や裏シフトの設定に）。
　　　　　　　　　色付きのセルは担当が入っている時間で、— にすると割当も外れます。「元に戻す」で取り消せます。
　　　　　　　　　「この日にメンバーを追加」で、回答していない日やCSVにいない人も追加できます。
　3 メンバー　　：ステータス・所属店舗・アイス・車・役職の希望を確認・修正します。氏名検索と店舗での絞り込みができます。
　　　　　　　　　ステータスか所属店舗が未設定の人は薄い黄色で表示されます。
　4 役職ルール　：役職ごとに、担当に必要な最低ステータスを設定します。
　5 シフト調整　：シフト表を作ります（下記）。

※ 2・3・5 のタブは、CSVを読み込むと使えるようになります。読み込むと自動で「5 シフト調整」に移動します。


■ シフト調整の使い方
【基本の流れ】
1. 「✦ 自動割当」で、条件に合うメンバーを一括で割り当てます（基本1時間のまとまりで入れます）。
2. 空いている枠（オレンジの点線「空き」）を、手作業で埋めたり入れ替えたりして調整します。
3. 「勤務状況チェック」で、一人あたりの勤務時間や、やりたい役職に1つも入っていない人を確認します。
4. 「印刷ビュー」または「CSVを書き出す」で出力します。

【表示の切り替え】
・日付ボタン：前日準備／本番1日目／本番2日目／3日分を一覧（3日分を縦に並べて表示）を切り替えます。ボタンの％はその日の充足率です。
・店舗ボタン：本店／2号店／くれあ／美化 などで列を絞り込めます（未割当の件数つき）。
・役職別／個人別：
　役職別＝行が時間（30分ごと）、列が役職の各番目（例：ドリッパー1〜6、リベロ1〜3）。1セルに1人です。
　個人別＝行が時間、列がメンバー。各セルにその人の担当が出ます。担当のセルを押すと変更できます。
・フルネーム：名前は通常、姓だけを表示します（同じ姓の人は名の1文字目まで）。オンにすると全員フルネームになります。
　※ 氏名に空白が入っていない場合（例：佐藤あかり）は姓を推定しているため、ずれることがあります。
　　 CSVの氏名を「佐藤 あかり」のように空白で区切ると確実です。
・全画面：シフト表だけを画面いっぱいに表示します（Escで戻ります）。

【セルの見方】
・オレンジ点線＝空き、灰色点線＝候補なし、黄色＝苦手な役職、赤＝同じ時間に別の枠と重複、斜線＝その時間は不要（押すと必要人数を設定）
・名前の前の ★＝やりたい役職、△＝苦手な役職
・ドリッパーの名前の右はアイスの可否：○＝1杯・2杯とも、青の1／2＝その杯数のみ、赤のH＝アイス不可（ホットのみ）
・ドリッパー1・2 は上級生の枠です。
・時間の列の「車2」は、その時間に参加できて、どの枠にも入っていない車持ちの人数です。0人の時間は赤で表示されます。
・マウスを重ねると、フルネームとその日の勤務時間が表示されます。

【担当者を変える】
・担当者の名前（または「空き」）を押すと、その時間・役職の条件に合うメンバーが一覧で出ます。
　「空いている人」と「別の枠で勤務中の人」に分かれ、名前で絞り込めます（↑↓で選んでEnter）。
　「長さ」で、30分／1時間（標準）／1.5時間／2時間／最大 を選ぶと、同じ役職の次の枠にもまとめて入れます。
　別の枠で勤務中の人を選ぶと、その枠から外してこちらに移します。
・名前をドラッグすると、別の枠へ移動・入れ替えできます（1時間のまとまりで入っている人は、まとめて移動します）。
　スマホ・タブレットは長押ししてからドラッグします。
・割当や移動のあとに出る「元に戻す」（または ⌘Z／Ctrl+Z）で、直前の操作を取り消せます。

【必要人数を変える】
・「必要人数を設定」ボタン、または斜線のセルを押すと、右側に設定パネルが開きます。
・役職×時間帯の表で人数を入力すると、すぐシフト表に反映されます。変更した箇所は青色になります。
・「一括」に入力すると、その役職の全時間帯をまとめて変更できます。
・「この日を標準に戻す」で、その日の人数を初期値に戻せます。

【印刷・PDF保存（印刷ビュー）】
・右上の「🖨 印刷ビュー」を押すと、印刷用の画面が別ウィンドウで開きます（シフト表で表示中の日が選ばれた状態）。
・左上で「シフト表」と「個人TT」を切り替え、上部のボタンで印刷する日を選びます。選んだ日だけが印刷されます。
・シフト表：1日分は A4横で、1ページ目がシフト表、2ページ目がその日の個人別シフト（誰が何時にどこへ入るか）です。
　1ポジション1列（例：ドリッパー 1〜6、リベロ 1・2・3）。黒塗り＝その時間は配置なし、空欄＝未割当。
　「個人別シフトも印刷」のチェックを外すと、シフト表だけを印刷します。
・個人TT：列がメンバー、行が時間の表です（A4横に16人ずつ）。色付き＝担当、白＝参加できるが担当なし、斜線＝参加できない時間。
・「すべての日」を選ぶと、3日分と、全日程の個人別シフト（合計時間つき）をまとめて印刷します。
・名前はシフト表と同じく姓だけで表示します。「フルネーム」にチェックを入れると全員フルネームになります。
・PDFにする場合は、「印刷する」→ 印刷画面で「PDFに保存」を選んでください（ファイル名は「シフト_本番1日目」のようになります）。
・ブラウザの設定で別ウィンドウが開けない場合は、印刷用のHTMLファイルがダウンロードされます。それを開いて印刷してください。

【条件を変更したとき】
必要人数・メンバー情報・役職ルール・勤務可能時間を変更しても、割当はすべては消えません。
条件に合わなくなった割当だけが外れ、何枠外れたかが画面下に表示されます。
「割当をクリア」と、割当がある状態での「自動割当」は、実行前に確認が出ます。


■ 読み込むCSV（アンケート回答）の形式
列：氏名, ステータス, 所属店舗, アイス, 車の有無, やりたい役職, 苦手な役職, 日付, 開始時刻, 終了時刻
・1人が複数日参加する場合は、日付ごとに1行ずつ記入します。
・ステータスは「未合格／1年目合格／2年目合格／上級生」のいずれか（ドリッパーの上級生・下級生もこれで判定。上級生以外は下級生扱い）。
・所属店舗は「本店／2号店／くれあ」。複数の場合は「本店, くれあ」のように区切ります。
・アイスは「○（1杯・2杯とも）／1杯のみ／2杯のみ／×（アイス不可）」のいずれか。ホットは全員できる前提です。
　旧形式（「1杯ホット, 2杯アイス」のような列挙）も読み込めます。
・車の有無は「あり／なし」。前日準備の「買い出し」は車ありの人だけが候補になります。
・やりたい役職・苦手な役職は「レジ、ホール」のように複数可（美化も可）。自動割当で、やりたい役職を優先し、苦手な役職はなるべく避けます。
・日付は 2026-10-30 や 2026/10/30、時刻は 9:00 や 09:00 のどちらでも読み込めます（30分単位まで）。
・文字コードは UTF-8 と Shift_JIS（Excelで保存したCSV）のどちらでも読み込めます。
・「読み込み」タブの「テンプレートをダウンロード」「サンプルCSVをダウンロード」で見本を取得できます。
　形式の詳細は「読み込み」タブの「CSVの形式を見る」でも確認できます。
・読み込んだ内容は「メンバー」タブで修正できます。判別できなかった値は、読み込み結果にオレンジ色で表示されます。


■ イベント日程と役職
・シフトは30分単位の枠で組みます（人を入れるときは基本1時間）。
・10/30（金）前日準備：「準備」の係ごとに配置します（店舗準備〈本店／2号店／くれあ〉・実委からの受け取り・買い出し・昼食・休憩・最終オペ練）。
　店舗準備はその店舗の所属メンバーだけ、買い出しは車ありの人だけが候補です。
・10/31（土）・11/1（日）本番：店舗ごとの役職で配置します。店舗の右に「美化」（各時間3人）があります。
・ドリッパー1・2（上級生の枠）は「上級生」のみ。ドリッパー3〜6 は、上級生以外を下級生として2〜3人入れます。


■ 共有方法
このフォルダ、または ShiftMaker_Offline.zip を、USBメモリ・社内の限定フォルダ・暗号化したファイル共有などで、必要な人だけに渡してください。

■ 注意
この配布版はローカルHTMLアプリです。ファイルを受け取った人はコピーできるため、パスワードなどの厳格なアクセス制御は行いません。
共有先を限定したい場合は、暗号化ZIPやアクセス権を設定した社内フォルダを利用してください。

■ データについて
CSVの読込、シフトの作成、CSV／印刷用HTMLの出力は、すべて各利用者のブラウザ内で行われます。データが外部に送信されることはありません。

■ 共同編集（GitHub Pages ＋ Firebase）
複数人で同じシフトをリアルタイムに編集できます。
・閲覧・編集：共有リンクを持っていて Google ログインした人
・CSVの読み込み・勤務可能表の編集：管理者だけ（共同編集を始めた人が自動で管理者になり、「👥 共同編集」画面から追加・削除できます）
・firebase-config.js が空のときは、これまでどおりオフラインで動きます。

【初回セットアップ（管理用アカウント cafeore2016@gmail.com で行う）】
1. https://console.firebase.google.com/ に cafeore2016@gmail.com でログインし、「プロジェクトを作成」（Google アナリティクスは不要）。
2. 「構築」→「Authentication」→「始める」→ ログイン方法で「Google」を有効にする。
   「設定」→「承認済みドメイン」に GitHub Pages のドメイン（cafeore-tkb.github.io）を追加する。
3. 「構築」→「Firestore Database」→「データベースを作成」（ロケーション：asia-northeast1〈東京〉、本番環境モード）。
4. 「ルール」タブに firestore.rules の中身を貼り付けて「公開」する。
   （または、ターミナルで firebase login → firebase use --add → firebase deploy --only firestore:rules）
5. 「プロジェクトの設定」→「マイアプリ」→ ウェブアプリ（</>）を追加し、表示された firebaseConfig を firebase-config.js に貼り付ける。
6. 公開URL：https://cafeore-tkb.github.io/sohosai-shift/（リポジトリ cafeore-tkb/sohosai-shift の main ブランチを GitHub Pages で公開）

【使い方】
1. https://cafeore-tkb.github.io/sohosai-shift/ を開き、CSV を読み込む（またはサンプルを読み込む）。
2. 「👥 共同編集」→ Google でログイン →「共同編集を始める」。
3. 表示されたリンクを担当者に共有する。開いた人は Google ログインすると参加できます。
・同じ枠を同時に変更した場合は、あとから変更した内容が残ります。
・リンク（#room=…）を知っている人は誰でも閲覧・編集できるので、担当者以外には共有しないでください。
